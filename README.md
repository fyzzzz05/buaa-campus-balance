# 校园余额

在本机查看北航校园卡、校园网和宿舍电费的余额及近期变化。校园卡消费按真实流水统计，校园网按学校结算日统计流量；照明和空调分别显示。

## 本机运行

需要 Node.js 22 或更新版本，以及能够访问相关学校服务的网络。首次运行：

```sh
npm ci
./start-web.command
```

打开 http://127.0.0.1:4174，在页面输入自己的统一身份认证账号和密码。校园网密码与统一身份认证密码相同时，可在登录页面选择复用。按 Control-C 停止服务；macOS 用户也可以双击 `start-web.command` 启动。

登录后选择「宿舍设置」，填写宿舍名称、照明电表号和空调电表号。学校电表接口按电表号查询，暂不支持仅凭楼栋和房间自动查找。学校的数据可能延迟，查询不到时面板会显示不可用。

如果你有自己的 `buaa-electricity-monitor` GitHub 仓库，且其 `main/data/history.csv` 包含上述电表号，可在设置中填写 GitHub 用户名，以显示历史记录。系统会验证历史文件的电表号，避免显示其他宿舍的数据。历史文件必须能通过 GitHub 的公开原始文件地址访问；不要在仓库中公开不愿分享的数据。

## 数据与安全

- 服务只监听本机 `127.0.0.1`，不是公开多用户服务；本项目不建议直接暴露到公网。
- 账号密码用于通过学校认证，不写入项目文件。选择自动重新登录时，密码保存在 macOS 登录钥匙串，学校会话过期时按需读取；退出面板时会从钥匙串删除。学校若要求验证码或其他验证，仍需手动登录。
- 勾选复用校园网密码后，其摘要保存在加密的本机会话 Cookie 中。未启用自动登录的 Cookie 在 12 小时后过期；启用时为 30 天，每次成功查询后更新，退出时失效。
- 宿舍设置、校园卡余额采样和本地会话密钥保存在当前用户的 `~/Library/Application Support/CampusBalance`，不提交 Git。不同登录账号的设置独立保存。
- 电费历史展示相邻日期的余额减少估算；充值、缺失日期等情况不能视为真实消费流水。
- 校园卡和校园网数据来自学校服务。服务不可用、认证过期、额外验证或网络不通时需要重新处理。

测试：`npm test`。

## macOS 更新与发布

App 左上角「校园余额 → 检查更新…」使用 Sparkle 检查 GitHub Releases。首次需要安装支持更新的版本；之后更新由应用提示并安装。更新包和更新描述均使用 Ed25519 签名，私钥保存在维护者的钥匙串及 GitHub Actions Secret 中。

维护者推送形如 `v1.0.1` 的版本标签后，GitHub Actions 会测试、构建 Apple Silicon 版本、签名并发布 Release。应用由临时签名构建，未使用 Apple Developer ID 签名或 Apple 公证；其他 Mac 首次安装时可能出现系统验证提示。使用前请先在目标网络确认能够访问 GitHub。
