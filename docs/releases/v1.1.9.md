- macOS 桌面小组件右上角新增刷新按钮，点击即可查询四项最新余额，无需打开主窗口。需要先在应用中开启自动重新登录；学校要求验证码时仍需打开应用完成验证。
- 连续点击刷新会合并为一次查询；刷新期间仍可查看上次余额，失败时保留已有数据并允许重试。

1.1.8 可通过「校园余额 → 检查更新…」下载、安装并重新启动。1.1.7 及更早版本需手动下载安装一次。下载 `CampusBalance-v1.1.9-macOS-arm64.dmg`，打开后拖入「应用程序」。`appcast.xml` 为应用读取的更新元数据，无需手动下载。

支持 Apple 芯片 Mac，要求 macOS 13.5 或更新版本；桌面小组件要求 macOS 14 或更新版本。应用尚未使用 Apple Developer ID 签名和公证。
