- macOS 支持应用内更新：在「校园余额 → 检查更新…」中检查、下载，确认后安装并重新启动，无需跳转 GitHub 或手动替换应用。应用也会定期检查新版本，安装仍由用户确认。
- 更新包及更新描述文件经过 Ed25519 签名校验。
- 修复原路径更新应用后，小组件后台服务可能继续使用旧密钥的问题。

1.1.7 及更早版本需手动下载安装一次本版本，之后即可使用应用内更新。下载 `CampusBalance-v1.1.8-macOS-arm64.dmg`，打开后拖入「应用程序」。`appcast.xml` 为应用读取的更新元数据，无需手动下载。

支持 Apple 芯片 Mac，要求 macOS 13.5 或更新版本；桌面小组件要求 macOS 14 或更新版本。应用尚未使用 Apple Developer ID 签名和公证。
