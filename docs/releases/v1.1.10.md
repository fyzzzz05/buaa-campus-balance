- 修复点击小组件刷新后，等待查询结果期间无法继续切换余额类别的问题。现在点击后立即交回交互控制，查询在后台继续。
- 刷新时在右上角显示动态进度环，结束后恢复刷新图标；超时或后台退出时不会一直停留在刷新状态。
- 小组件扩展版本号跟随应用版本更新。

1.1.8 及更新版本可通过「校园余额 → 检查更新…」下载、安装并重新启动。小组件刷新需要在应用中启用自动重新登录；macOS 提示钥匙串权限时，需要允许后台刷新程序读取已保存的密码。学校要求验证码时仍需在应用中验证。

支持 Apple 芯片 Mac，要求 macOS 13.5 或更新版本；桌面小组件要求 macOS 14 或更新版本。应用尚未使用 Apple Developer ID 签名和公证。
