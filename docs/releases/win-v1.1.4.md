首个 Windows 版（Electron）开发构建。

- 与 macOS 版共用同一套页面和数据逻辑：登录、校园卡与流量流水、电费、电表号设置、自动登录。
- 系统托盘常驻、开机自启、单实例；关闭窗口会收进托盘。
- 桌面小组件（置顶小窗）可拖动，点底部图标切换四项余额，点数值区打开主窗口并定位到对应项。
- 每天 08:30 与睡眠唤醒后自动刷新小组件数据；失败时保留上次成功值并标注「更新失败」。
- 自动登录密码使用系统凭据加密（Electron safeStorage），诊断日志不记录账号、密码或 Cookie。

安装包未签名，首次运行会出现 Windows SmartScreen 提示。支持 Windows 10/11 x64。
