Windows 版改用托盘弹窗展示余额，不再使用浮动置顶小组件。

- 单击任务栏托盘图标即在图标旁弹出/收起弹窗；点空白处或按 Esc 关闭。
- 四项余额一行一个，点开可在行内查看近 14 天柱状走势，↑↓ 切换、行内显示日均与最高值。
- 弹窗底部可直接「打开完整窗口」（定位到当前展开项）或「电表号设置」。
- 弹窗锚定在托盘图标旁，适配底部/顶部/左右侧任务栏，行展开时窗口高度自动变化且不越界。
- 每日 08:30 与睡眠唤醒后台刷新、自动登录、托盘常驻和开机自启行为保持不变。

安装包未签名，首次运行会出现 Windows SmartScreen 提示。支持 Windows 10/11 x64。
