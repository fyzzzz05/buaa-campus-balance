## 更新内容

- 修复免费流量耗尽后返回 `0byte`，导致校园网余额无法显示的问题。
- 适配学校电费页面的字段变化。电费优先通过 HTTPS 查询，连接失败或超时后尝试 HTTP，并在界面注明「HTTP 查询」。
- 区分连接失败、请求超时、登录失效、HTTP 错误和页面解析失败；增加本机诊断日志，历史余额兜底时保留实时查询失败原因。
- 使用新的校园余额应用图标。
- 增加 macOS 常用菜单与快捷键：`⌘W` 关闭窗口、`⌘Q` 退出、`⌘M` 最小化、`⌘H` 隐藏，以及全选、拷贝、粘贴、剪切、撤销和重做。关闭窗口后可点击 Dock 图标重新打开。
- 「帮助 → 打开诊断日志」可定位日志文件；「下载更新…」打开 GitHub 最新版下载页。

## 下载与安装

下载 `CampusBalance-v1.1.3-macOS-arm64.dmg`，打开后将应用拖入「应用程序」。支持 Apple 芯片 Mac，要求 macOS 13.5 或更新版本；桌面小组件要求 macOS 14 或更新版本。

仅提供 DMG 安装包，请手动下载安装。应用未使用 Apple Developer ID 签名与公证。
